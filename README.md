## Backend starten

Zum starten des backends müssen Sie zuerst im Terminal zu "angular-php-app\backend\api" navigieren.
Danach führen Sie "php -S localhost:8000" aus.

## Frontend starten

Zum starten des frontends müssen Sie zuerst im Terminal zu "angular-php-app\frontend\app" navigieren.
Danach führen Sie "npm install" aus.
Danach führen Sie "npm start" aus.
Nun lässt sich die Anwendung im Browser unter "http://localhost:4200/" starten.
